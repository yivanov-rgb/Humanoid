# Штатные движения линии

По вашему подтверждению `forward_one_step`, `turn_left`, `turn_right`, `move_left` и `move_right` испытаны на реальном роботе. `line_follow.py` вызывает их через штатный `MotionManager.run_action` без повторной проверки диапазонов сервоприводов. Заполнять пределы или передавать JSON не требуется.

[Команды запуска](LINE_TEST_RU.md). Прямые команды отдельным сервоприводам в сценарии линии не используются; проверенный `tag_grab.py` не менялся.
