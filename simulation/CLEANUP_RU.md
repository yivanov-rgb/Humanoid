# Очистка проекта

18 октября 2026 года удалены:

- 5 каталогов `__pycache__` с восстановимым байткодом Python;
- 7 старых журналов без ссылок из исходников, документации и JSON-отчётов;
- 3 синтетических `.d6a`, повторно создаваемых `tests/check_action_replay.py --make-fixtures`;
- 50 лишних распакованных файлов: `action_bk` и записи `.ros`. Каждый перед удалением побайтно сверен по SHA-256 с сохранённым исходным архивом.

Освобождено около 1,3 МиБ. Сохранены все 48 основных действий, 9 рабочих копий в `simulation/actiongroups`, исходный архив всех 98 действий, скрипты, тесты, документация, PDF, актуальные и исторические отчёты, на которые есть ссылки. Контрольные суммы 61 сохраняемого файла проверены до и после очистки. Корневые ссылки на скрипты `robot/` работают.

Основной объём — около 23 МиБ — занимает закреплённая версия HiWonder в `simulation/vendor`. Она сохранена для локальной сборки и изучения исходников. Docker-образы и файлы вне проекта не удалялись; симулятор при очистке не запускался.

Для повторной распаковки полного архива из корня проекта:

```bash
mkdir -p simulation/artifacts/d6a_from_robot
tar -xzf simulation/artifacts/ainex_d6a.tar.gz \
  -C simulation/artifacts/d6a_from_robot
```

Поля путей резервных файлов в `actiongroups_manifest.json` относятся к первоначальной инвентаризации; после очистки эти файлы доступны в архиве.
