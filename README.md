и локальной симуляции находятся в отдельных руководствах.

- [Ручной запуск, проверка начальной стойки и остановка](simulation/README.md#ручной-запуск-и-остановка).

Симуляцию запускает и перезапускает пользователь вручную. Результат в Gazebo
не подтверждает физическое испытание; настройки модели и рабочая калибровка
робота рассматриваются отдельно.
